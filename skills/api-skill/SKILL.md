# API Skill Suite

Tập hợp toàn diện các bộ công cụ phát triển và kiểm thử API:
- **API Design & Specs**: OpenAPI spec generation, API designer, versioning helper.
- **Testing & Mocking**: Postman collections, Newman CI/CD test automation, API mocking.
- **Security & Compliance**: API security patterns, rate-limiting, compliance audits.
- **Protocols**: REST, GraphQL, gRPC helpers.

Tra cứu tài liệu chi tiết tại các thư mục con tương ứng bên trong `api-skill/`.
